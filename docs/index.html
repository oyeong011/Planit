Google data use

Calen asks for calendar access because it is a calendar planner.

Google Calendar data is used to show your events, find open time, and create, edit, move, or delete calendar items you request. Calen does not use Google user data for ads or sell it to third parties.

Read the Privacy Policy
calendar.events

Used to display Google Calendar events and let the user create, edit, move, or delete events inside Calen.

calendar.calendarlist.readonly

Used to list the user's calendars, show calendar names, and let users choose which calendars are visible or sensitive.

userinfo.email

Used to show which Google account is signed in and to store OAuth tokens under the right local Keychain account.

Privacy boundary

A Mac app first, a cloud account never.

This homepage is public and explains Calen before sign-in. OAuth tokens are stored in macOS Keychain, and destructive calendar actions stay user-confirmed.

  • No Calen cloud server receives your calendar data.
  • Local AI integrations are optional and user-controlled.
  • The Privacy Policy is available without login.
